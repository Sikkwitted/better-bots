# Support

Better Bots is preview software maintained by volunteers. There is no guaranteed
support or response time.

- **Questions and ideas:** use GitHub Discussions.
- **Bugs:** open an issue with the bug report form. Include steps to reproduce and
  remove secrets and private data first.
- **Security problems:** report them privately; see [SECURITY.md](SECURITY.md).

Before asking, check the [README](README.md), [operations](docs/operations.md),
and the [CHANGELOG](CHANGELOG.md).
